## Instalação

[](https://github.com/marcusolsson/obsidian-projects#installation)

Nota

Você deve desligar **Modo restrito** para usar Projetos.

1. Em Obsidian, aberto **Configurações**.
2. Sob **Plugins comunitários**, selecione **Navegar**.
3. Procure por "Projetos" de Marcus Olsson e selecione-o.
4. Selecionar **Instalar**.

Para começar a usar Projetos, pressione **Ctrl+P** (ou **Cmd+P** no macOS) para abrir o **Paleta de comando**, e então selecione **Projetos: Mostrar projetos**.

## Filosofia Design

[](https://github.com/marcusolsson/obsidian-projects#design-philosophy)

Ao desenvolver qualquer software, muitas vezes você se depara com escolhas difíceis. Para ajudar a orientar as decisões de design, este projeto adere aos seguintes princípios:

- **Não deixe rastro:** O plug-in não deve deixar nenhuma configuração específica do plug-in nas notas, como propriedades personalizadas do front matter. As anotações podem ser compartilhadas com colegas e equipes que não usam o Obsidian. Se o usuário parar de usar este plugin, ele não precisará limpar todas as suas anotações.
- **Mantenha-o nativo:** O plugin deve parecer e parecer nativo do Obsidian. O plugin também deve preferir APIs Web nativas sobre componentes personalizados sempre que possível.
- **Estabilidade sobre características:** Este plugin é voltado para profissionais com altas demandas de confiabilidade. Quaisquer relatórios de bugs e problemas de usabilidade serão priorizados em relação aos novos recursos.
