Consultas Inline: Casos de uso e Limitações

Ao contrário de um bloco de dataview normal com três backticks, as consultas inline de dataview são, como o nome sugere, para o uso inline em texto, títulos ou similar a exibir dinamicamente valores no fluxo de sua nota, em vez de exigir um bloco isolado para eles.  
Consultas Inline **sempre produza exatamente um valor**. Dado isso, não é possível realizar operações de coleta de páginas com eles - **Os tipos de consulta não podem ser usados dentro de Consultas Inline**. Em vez disso, eles usam [expressões](https://blacksmithgu.github.io/obsidian-dataview/query/expressions/).  
[Documentação](https://blacksmithgu.github.io/obsidian-dataview/data-queries/#inline-dql)

_Esta é uma consulta inline - vista no modo de origem para ver o código:_ `= this.file.name`

### DataviewJS[¶](https://s-blu.github.io/obsidian_dataview_example_vault/20%20Dataview%20Queries/Basic%20Inline%20Queries/#dataviewjs "Link permanente")

Consultas Inline Dataview JS

DataviewJS Inline Queries em contrário tem tudo disponível que um `dataviewjs` bloco pode usar, tornando-os imensamente poderoso. Eles precisam ser explicitamente ativados nas Opções Dataviews.  
[Documentação](https://blacksmithgu.github.io/obsidian-dataview/data-queries/#inline-dataview-js)

_Esta é uma consulta inline - vista no modo de origem para ver o código:_ `$= dv.current().file.name`

### Use funções dataview[¶](https://s-blu.github.io/obsidian_dataview_example_vault/20%20Dataview%20Queries/Basic%20Inline%20Queries/#use-dataview-functions "Link permanente")

[Funções dataview](https://blacksmithgu.github.io/obsidian-dataview/query/functions/) estão disponíveis em consultas inline.

Permite melhor aparar esta descrição para baixo para "`= truncate(this.description, 20, "...")`" é o suficiente para ver o começo.

**Verifique se os meta dados importantes estão definidos**  
descrição: `= choice(contains(this, "description"), "Set", "Missing!")`  
tópicos: `= choice(contains(this, "topics"), "Set", "Missing!")`  
algumOutroCampo: `= choice(contains(this, "someOtherField"), "Set", "Missing!")`

Embora você não possa escrever Consultas no sentido tradicional, você ainda pode acessar links concretos e suas propriedades.

O "`= [Learn the Basics](../30 Dataview Resources/33 Use Cases/Learn the Basics.md).file.link`" O caso de uso existe desde então `= [Learn the Basics](../30 Dataview Resources/33 Use Cases/Learn the Basics.md).file.ctime` e contém **`= length([Learn the Basics](../30 Dataview Resources/33 Use Cases/Learn the Basics.md).file.outlinks)` outlinks** - `= choice(length(filter([Learn the Basics](../30 Dataview Resources/33 Use Cases/Learn the Basics.md).file.outlinks, (x) => meta(x).path = this.file.path)), "including one to this file", "but none to this file")`.

### Formatação de consultas inline[¶](https://s-blu.github.io/obsidian_dataview_example_vault/20%20Dataview%20Queries/Basic%20Inline%20Queries/#formatting-inline-queries "Link permanente")

Consultas Inline são tratadas como texto

Você pode formatar uma consulta inline como formataria o texto normal.

Hoje é **`= date(today)`**, é **`= dateformat(date(now), "HH:MM")`**.

#### O título do arquivo é "`= this.file.name`"[¶](https://s-blu.github.io/obsidian_dataview_example_vault/20%20Dataview%20Queries/Basic%20Inline%20Queries/#this-file-title-is-thisfilename "Link permanente")

_Última edição: `= this.file.mtime`_

### Usando uma consulta inline como um valor de meta dados[¶](https://s-blu.github.io/obsidian_dataview_example_vault/20%20Dataview%20Queries/Basic%20Inline%20Queries/#using-a-inline-query-as-a-meta-data-value "Link permanente")

Calcular um campo de meta dados

Você pode atribuir consultas inline a um campo de meta dados para usar esse cálculo em outros lugares, ou seja, em uma consulta de visualização de dados regular.

existeDesde:: `= date(now) - this.file.ctime`

`LIST existsSince WHERE existsSince`

DataviewJS Inline

Com a ajuda de consultas Inline DataviewJS, você pode até mesmo atribuir consultas completas a um campo de meta dados. Esta é uma técnica bastante avançada, no entanto.

<font color="#ff007f">Muito útil para listar dados de notas</font> :: `$= dv.pages('"Biblioteca/Livros"').groupBy(p => p.Autor).key`

`LIST allAuthorsInVault WHERE allAuthorsInVault`

Leituras: `$= dv.pages('"Agenda"').groupBy(p => p.Leitura).key`

`LIST allAuthorsInVault WHERE allAuthorsInVault`
